# loadgen: an agent-shaped load driver for the control plane

Date: 2026-09-20

`server/cmd/loadgen` drives the control plane with the load shapes
agent runtimes actually produce and reports what happened — per-op
latency percentiles, error counts by status code, and deltas of the
server's own metric counters. `make load` runs a one-minute mixed
smoke; flags vary shape, sessions, duration, and mode.

- **Two modes.** `embedded` (default) boots an in-process server on a
  loopback listener — memory store by default, Postgres when
  `TOOLPLANE_DATABASE_URL` is set, so the store is load-testable with
  no extra wiring. `external` drives any running server via
  `--address`.
- **Provider side included.** In-process fake providers speak the real
  provider loop (`RegisterMachine`, `ClaimNextRequest`, heartbeats,
  `AppendRequestChunks`, `SubmitRequestResult`), so driven load
  exercises dispatch and execution, not just ingress. One tool resolves
  immediately; the other streams 1KiB chunks at 10/s for 30s — the
  token-stream shape continuous-output tools (and inference endpoints)
  produce.
- **Shapes.** `agent-turn` (discover → burst of synchronous invokes →
  repeat), `token-stream` (concurrent long streams followed end to
  end), `heartbeat-fleet` (machines that only ping), `discovery-churn`
  (ListTools pressure), `mixed` (all of the above).
- **Report.** JSON on stdout and optionally `--report <file>`: op
  counts with p50/p95/p99/max, error counts by gRPC code, chunks
  followed, and `toolplane_*` metric deltas (gRPC counters, requeues,
  dead letters, serialization retries; final levels for queue depth and
  inflight gauges). Ops cut short by the run window ending are recorded
  as `-partial` counts, not failures.
- **Exit code.** 0 when every driven op succeeded, 1 otherwise — a run
  with unexpected failures is red wherever it runs.

Notes: the fake providers poll claims every 50ms when idle, matching
the real provider's cadence, so idle sessions contribute claim-poll
load by design. Numbers are hardware-relative; compare runs from the
same host only.
